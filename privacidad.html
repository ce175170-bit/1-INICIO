Política de Privacidad

Aplicación oficial del Colegio Juan Francisco Bohórquez

1. Información general

La presente Política de Privacidad describe cómo se trata la información relacionada con la aplicación oficial del Colegio Juan Francisco Bohórquez (Colegio J.F.B.), ubicado en Betanzos, Potosí, Bolivia.

La aplicación tiene como finalidad facilitar el acceso a información institucional, noticias, comunicados, recursos educativos y novedades del Colegio J.F.B.

2. Información que puede recopilarse

La aplicación no solicita al usuario crear una cuenta ni ingresar información personal para utilizar sus funciones principales.

Para determinadas funciones técnicas, como el envío de notificaciones, pueden procesarse identificadores técnicos del dispositivo o de la aplicación necesarios para que el servicio funcione correctamente.

3. Notificaciones

La aplicación puede utilizar servicios de notificaciones para enviar comunicados, avisos y novedades del Colegio J.F.B.

Para proporcionar este servicio pueden utilizarse servicios tecnológicos de terceros, como Firebase Cloud Messaging de Google.

4. Uso de la información

La información técnica que pueda ser procesada se utiliza únicamente para proporcionar, mantener, proteger y mejorar las funciones de la aplicación, incluyendo el funcionamiento de las notificaciones.

El Colegio J.F.B. no utiliza la aplicación para vender información personal de los usuarios.

5. Servicios de terceros

La aplicación puede utilizar servicios proporcionados por terceros para determinadas funciones técnicas.

  • Google Firebase Cloud Messaging, para el envío de notificaciones.
  • Servicios de alojamiento y publicación del sitio web institucional.

Estos servicios pueden procesar información técnica de acuerdo con sus propias políticas de privacidad y condiciones de servicio.

6. Sitio web y enlaces externos

La aplicación puede mostrar contenido del sitio web institucional del Colegio J.F.B. También puede contener enlaces hacia servicios externos.

Cuando el usuario accede a un servicio externo, el tratamiento de la información queda sujeto a la política de privacidad del servicio correspondiente.

7. Seguridad

Se aplican medidas razonables para proteger la información relacionada con la aplicación y evitar accesos no autorizados, alteraciones o usos indebidos.

8. Privacidad de los menores

El Colegio J.F.B. procura que la aplicación se utilice de manera responsable y educativa. La aplicación no solicita deliberadamente información personal de los estudiantes para utilizar sus funciones principales.

9. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando sea necesario para reflejar cambios en la aplicación, sus servicios o los requisitos legales y de Google Play.

Cualquier actualización será publicada en esta misma página.

10. Contacto

Para consultas relacionadas con esta Política de Privacidad o con la aplicación del Colegio J.F.B., los usuarios pueden comunicarse con el Colegio Juan Francisco Bohórquez a través de sus canales oficiales de contacto.
